Datensicherung

Die Einträge werden nur in diesem Browser auf diesem Gerät gespeichert. Für einen Gerätewechsel regelmäßig eine Sicherung erstellen.

Tipp: Für eine App auf dem Home-Bildschirm muss diese Seite über eine HTTPS-Webadresse in Safari geöffnet werden. Eine lokal heruntergeladene HTML-Datei lässt sich nicht zuverlässig als vollwertige iPhone-App installieren. Bereits in Version 3 gespeicherte Einheiten werden beim ersten Öffnen im selben Browser übernommen, sofern der Speicherbereich derselbe ist.
